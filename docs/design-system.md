# Design System

Quelle: `.claude/rules/frontend.md` (Firmen-Design-Tokens)

## Farben
| Token | Wert | Verwendung (Empfehlung) |
|-------|------|--------------------------|
| Primary | `#007ec1` | Primäraktionen, Links, aktive Zustände |
| Primary Dark | `#00406e` | Header, Navigation, Hover |
| Primary Darkest | `#000824` | Text auf hellem Grund, Akzente |

Statusfarben (freigegeben / zu überarbeiten / gesperrt) ergänzend aus den Tailwind-Standardpaletten (grün / amber / grau), sofern keine Firmenvorgabe existiert.

## Typografie
- Schrift: **Noto Sans**

## Grundsätze
- Sachliche, tabellenorientierte Fachanwendungs-Optik, helles Theme
- Komponenten: shadcn/ui (siehe `.claude/rules/frontend.md`)
